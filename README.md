# Invito alla laurea di Sonia

Pagina d'invito con conferma di partecipazione (RSVP), pubblicata con GitHub Pages.

- `index.html` — la pagina. Tutti i dati (data, orario, luogo, foto, link del foglio risposte) sono nell'oggetto `CONFIG` in fondo al file.
- `foto-sonia.jpg`, `foto-sonia-2.jpg` — le foto.
- `apps-script/Codice.gs` — lo script da incollare in Apps Script nel foglio Google che riceve le risposte.
